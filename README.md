# Goddess Sakiko（アワーノーツ最適編成ツール）

バンドリ！アワーノーツの手持ちカードから、目的別の最適編成を探す非公式ツールです。

**公開ページ:** https://sekiguchi-sechi.github.io/awano-lab/

## できること

- 持っているメンバー・スナップを登録（Lv・特訓・覚醒などを選ぶと総合力やスキルの値を自動で計算）。バンド・レア度・タイプで絞り込み、並べ替えができます
- 楽曲一覧（バンド・タイプ・長さ・撃奏区間・必要スコア）
- 目的を選んで最適編成を計算：フリーのスコア最大、イベントpt・バッジ最大（フリー＋チャレンジ）、チャレンジのスコア最大、撃奏ライブのスコア最大
- 手持ちのファイル書き出し・読み込み（JSONで手持ちやキャラクターランクなどを一括更新）

手持ちの情報はお使いのブラウザ内（localStorage）にのみ保存されます。サーバーには何も送信しません。

## データについて

予想スコアの誤差の目安は、フリー・チャレンジで±3%、撃奏で±8%程度です。ゲーム内の表示を優先してください。

このページは非公式のファンツールで、ゲームの権利者とは関係ありません。
